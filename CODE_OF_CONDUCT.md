# Code of Conduct

We want this project to be welcoming and productive for everyone.

## Be respectful

- Treat others with respect and kindness.
- Assume good intent and communicate constructively.
- Focus feedback on the work, not the person.

## Unacceptable behavior

- Harassment, hate speech, discrimination, or personal attacks
- Sexualized language or unwanted attention
- Trolling, threats, or repeated disruptive behavior
- Sharing someone’s private information without permission

## Maintainer actions

Maintainers may edit/remove content and may restrict or ban participation if behavior is harmful or repeatedly disruptive.

## Reporting

If something happens that violates this Code of Conduct, report it to the maintainers by opening an Issue (or, if sensitive, contact a maintainer directly). Please include context such as links/screenshots/logs.

## Scope

This applies to all project spaces: Issues, PRs, Discussions, and other community channels.
